# Clicker

Автокликер для Windows 11: выбираете кнопку мыши и интервал, включаете и выключаете глобальной горячей клавишей. Клики идут в текущую позицию курсора, в любое активное окно.

Стек: Rust, [eframe/egui](https://github.com/emilk/egui) (окно), [enigo](https://github.com/enigo-rs/enigo) (эмуляция кликов), [global-hotkey](https://github.com/tauri-apps/global-hotkey) (горячая клавиша).

## Требования

- Windows 11.
- Rust stable 1.85+ (edition 2024) через [rustup](https://rustup.rs).
- Visual Studio Build Tools с компонентом «Desktop development with C++» (нужен линкер MSVC для таргета `x86_64-pc-windows-msvc`).

## Сборка и запуск

```powershell
cargo build --release
.\target\release\clicker.exe
```

Для отладочной сборки с консолью используйте `cargo run`.

## Использование

| Настройка | Значения | По умолчанию |
|---|---|---|
| Кнопка мыши | левая, правая, средняя | левая |
| Интервал | 1 … 600 000 мс | 100 мс |
| Горячая клавиша | F6, F7, F8, F9 | F6 |

1. Выберите кнопку, интервал и горячую клавишу.
2. Нажмите горячую клавишу или кнопку «Старт». Первый клик выполняется сразу, дальше по интервалу.
3. Нажмите горячую клавишу или «Стоп», чтобы остановить. Счётчик кликов показывается в окне.

Настройки блокируются, пока кликер работает.

## Ограничения

- Клики в окна, запущенные от администратора, блокируются Windows (UIPI), если сам кликер не запущен от администратора. В этом случае кликер остановится и покажет ошибку.
- Если горячая клавиша уже занята другой программой, регистрация не удастся: ошибка выводится в окне, выберите другую клавишу.
- Период между кликами равен интервалу плюс время самого клика; накопленная задержка не компенсируется.
- Настройки не сохраняются между запусками.
